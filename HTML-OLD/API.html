What is an API?

API (Application Programming Interface) is a set of rules that allows two software systems to communicate.

OAuth 2.0 Token Flow

sequenceDiagram
    participant User
    participant Client_App
    participant Auth_Server
    participant API_Server

    User->>Client_App: Login
    Client_App->>Auth_Server: Request Token
    Auth_Server-->>Client_App: Access Token
    Client_App->>API_Server: Request with Token
    API_Server-->>Client_App: Response
