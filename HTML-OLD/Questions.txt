Q9. What is the final output?
if (printf("%c", 'A') && printf("B")) {
    printf("C");
}
A) BC
B) AB
C) ABC
D) AC
Correct answer is: A) AC
printf("%c", 'A') executes first

It prints A

It returns 1 (true)

Because the first part of the OR (||) is already true,
the second printf("B") does NOT execute (short-circuit behavior).

Since the condition is true, the if body runs and printf("C") prints C.
