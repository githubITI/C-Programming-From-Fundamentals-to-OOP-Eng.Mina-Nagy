1. Arithmetic operators

1-1 Binary operators work using two operands:
	= 	Assignment 	a = b
	+ 	Addition 	a + b
	- 	Subtraction 	a - b
	* 	Multiplication 	a * b
	/ 	Division 	a / b
	% 	Modulo 	a % b
Misunderstanding integer division
5 / 2 = 2     // not 2.5

5 / 2.0   // 2.5
(float)5 / 2
Confusing = with ==
int a=5;
int b=6;
printf("%d",a=b);//6
int a=5;
int b=6;
printf("%d",a==b);//0

if (a = b)   // assignment! 
if (a == b)  // comparison
Remainder
  • remainder = a % b;
  • Only works with integer types (int, long, etc.).
  • Does not work with floats in standard C/C++ (though fmod() in can be used for floats).
//remainder can be computed using subtraction:
17 % 5
Repeated subtraction:
17 - 5 = 12  
12 - 5 = 7  
7  - 5 = 2   → stop (2 < 5)
//code 
x%y
while (x >= y) {
    x = x - y;
}
return x;   // this is remainder


 5  %  2 =  1
 5  % -2 =  1
-5  %  2 = -1
-5  % -2 = -1

5.5 % 2.0   // ❌ not allowed Using % with floats [Modulo only works on integers]
Use Cases for %

a) Check if a number is even or odd

    if (n % 2 == 0)
    printf("%d is even\n", n);
    else
        printf("%d is odd\n", n);
  • Logic: Even numbers are divisible by 2 → remainder 0.

b) Circular counting (wrap-around)

    int days = 7;
    int today = 5; // Friday
    int after3days = (today + 3) % days; // 1 → Monday
  • Useful in calendars, clocks, circular buffers.

c) Limit a number within a range

        int n = 23;
        int limit = 10;
        int result = n % limit; // 3 → value stays within 0-9
  • Keeps values within a fixed range.

d) Detect multiples of a number

        if (n % 5 == 0)
            printf("%d is a multiple of 5\n", n);

e) Hashing / Distribution

  • % is used to distribute values in hash tables.
    #define TABLE_SIZE 10
    int hashFunction(int key) {
        return key % TABLE_SIZE;
    }
    int main() {
        int key = 27;
        int index = hashFunction(key); // 27 % 10 = 7
        printf("Store key %d at index %d\n", key, index); 
        return 0;
    }
1-2 Unary operators only take one operand:
	+ 	Unary plus 	+a
	- 	Unary minus 	-a
	++ 	Increment 	a++ or ++a
	-- 	Decrement 	a-- or --a

int a = 5;
int b = +a;   // b = 5
int a = 5;
int b = -a;  // b = -5
//Increment Operator (++)
// (a) Post-increment: a++ [Uses the value first, then increments].
int a = 5;
int b = a++;   // b = 5, then a becomes 6
//(b) Pre-increment: ++a [Increments first, then uses the value]
int a = 5;
int b = ++a;   // a becomes 6, then b = 6
//Decrement Operator (--)
// (a) Post-decrement: a-- [Uses the value first, then decreases it].
int a = 5;
int b = a--;   // b = 5, then a = 4
// (b) Pre-decrement: --a [Decreases value first, then uses it].

int a = 5;
int b = --a;   // a = 4, b = 4

2. Compound Assignment Operators

Compound assignment operators combine an arithmetic operation with assignment.

Operator Meaning Example Equivalent To
+= Addition assignment a += b; a = a + b;
-= Subtraction assignment a -= b; a = a - b;
*= Multiplication assignment a *= b; a = a * b;
/= Division assignment a /= b; a = a / b;
%= Modulo assignment a %= b; a = a % b; 
    int a = 10, b = 3;
    a += b;  // a = 13
    cout << "a += b: " << a << endl;
    a -= b;  // a = 10
    cout << "a -= b: " << a << endl;
    a *= b;  // a = 30
    cout << "a *= b: " << a << endl;
    a /= b;  // a = 10
    cout << "a /= b: " << a << endl;
    a %= b;  // a = 1
    cout << "a %= b: " << a << endl;
Confusing unary + or - with compound assignments
//valid :: compound assignments
a += b;   // a = a + b;
a -= b;   // a = a - b;
//valid :: Unary operations:
a = +b;   // a = +3
a = -b;   // a = -3
❌ INVALID:
a =* b;   // error
a =/ b;   // error
a =% b;   // error

// =* is NOT the same as *=
//Compiler thinks *b means “dereference b” → illegal if b is not a pointer.
  • Unary plus (+) → just returns the positive value of b
  • Unary minus (-) → returns the negative value of b
  • =+ or =- valid
    a = 5; 
    b =3 ;
    a += b;  // a = a+b 
    //-------------------
    a = 5; 
    b = 3 ;
    a = -b;  // a = -3
  • Compound Assignment Operators += and -=
    • += → add and assign (a += b is a = a + b)
    • -= → subtract and assign (a -= b is a = a - b)
          a += b;  // a = a+b 
    a -= b;  // a = a-b
  • *, /, % cannot be directly combined with = in this form
  • Only valid compound assignments exist: a = b // multiply and assign a /= b // divide and assign a %= b // modulo and assign a = b // ERROR a =/ b // ERROR a =% b // ERROR
Expression Valid? Meaning / Result
a = +b ✔ Assign positive value of b to a
a = -b ✔ Assign negative value of b to a
a += b ✔ Add b to a and store in a
a -= b ✔ Subtract b from a and store in a
a =* b ❌ ERROR (not compound operator)
a =/ b ❌ ERROR
a =% b ❌ ERROR

a /= b ✔ Divide a by b

3.Comparison Operators

  • Comparison operators compare two values and return true (1) or false (0).
Operator Meaning Example
== Equal to a == b
!= Not equal a != b
> Greater than a > b
< Less than a < b
>= Greater than or equal to a >= b
<= Less than or equal to a <= b 
    int a = 5, b = 10;
    cout << (a == b) << endl;  // 0
    cout << (a != b) << endl;  // 1
    cout << (a > b) << endl;   // 0
    cout << (a < b) << endl;   // 1
    cout << (a >= b) << endl;  // 0
    cout << (a <= b) << endl;  // 1

4. Logical Operators

  • Logical operators are used to combine or negate boolean expressions.
Operator Name Example Meaning
! NOT !a Reverses boolean value (true → false, false → true)
&& AND a && b True if both a and b are true
\|\| OR a \|\| b True if a or b are true 
int a = 1;  // true
int b = 0;  // false

cout << (!a) << endl;   // 0
cout << (a && b) << endl; // 0
cout << (a || b) << endl; // 1
Common Mistakes
    int a=5;
    int b=0;
    // !A&&B  !=  !(A&&B)
    printf("%d\n", !a&&b);
    printf("%d\n",!(a&&b));
    // cond1 || cond2 && cond3 == cond1 || (cond2 && cond3) != (cond1 || cond2) && cond3
    int a=1;
    int b=1;
    int c=0;
    printf("%d\n",a || b && c );//1
    printf("%d\n",a || (b && c) );//1
    printf("%d\n",(a || b) && c );//0

5. Bitwise Operators

  • Bitwise operators work on individual bits of integer values.
  • work only on integers, not floats.
  • But there is a twist:Signed integers use Two’s Complement representation.
Operator Name Example Result
& AND 2 & 5 0 → 0010 & 0101 = 0000
\| OR 2\|5 7 → 0010 | 0101 = 0111
~ NOT ~2 -3 → flips all bits
^ XOR 2 ^ 5 7 → 0010 ^ 0101 = 0111
<< Left shift 2 << 1 4 → shift bits left by 1
>> Right shift 4 >> 1 2 → shift bits right by 1
Bitwise vs Logical Example
int a = 2, b = 5;
cout << (a & b) << endl;  // 0
cout << (a && b) << endl; // 1

Operator Precedence
  • Precedence determines which operator is evaluated first in an expression.
  • Higher precedence operators are evaluated before lower precedence ones.
a + b * c - b / c % 2
// Initial Value b=3 , c=2 ,a=5
/*    Steps
        b * c → 3 * 2 = 6
        b / c → 3 / 2 = 1  // integer division
        1 % 2 → 1

        a + 6 - 1
        a + 6 → 5 + 6 = 11
        11 - 1 → 10
*/
cond1 || cond2 && cond3
//&& has higher precedence than ||
cond1 || (cond2 && cond3)
Operator Associativity

  • Associativity decides the order of evaluation when two operators have the same precedence.

  • Can be Left to Right or Right to Left.

Operator Associativity
+ - * / % Left to Right
= Right to Left
++ -- (prefix) Right to Left
++ -- (postfix) Left to Right

Example: Common Mistakes Fixed
int a = 5, b = 2;
float result;

// ❌ Wrong: integer division
result = a / b; // result = 2
cout << "Wrong: " << result << endl;

// ✅ Correct
result = (float)a / b;
//or
result = static_cast<float>(a) / b;

cout << "Correct: " << result << endl;

// ❌ Wrong: assignment instead of comparison
if (a = b) cout << "Equal\n";   // always true!
// ✅ Correct
if (a == b) cout << "Equal\n";

// ❌ Wrong: using % with float
// float x = 5.5 % 2; // ERROR
// ✅ Correct
float x = fmod(5.5, 2.0);
cout << "fmod result: " << x << endl;
